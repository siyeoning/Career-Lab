## 2. 개발 목적

Career Lab은 실무 경험과 기술 학습을 연결하고,
개인의 기술 역량 및 커리어 성장 과정을 체계적으로
관리하기 위한 AI 기반 플랫폼이다.

본 플랫폼은 목표 직무에 필요한 기술 역량을 정의하고,
현재 보유 역량과의 차이를 분석하여 학습 및 실습 과제를
관리할 수 있도록 지원한다.

또한 플랫폼 개발 과정에서 소프트웨어 설계, AI 모델 연동,
클라우드 배포 및 시스템 최적화 경험을 확보하는 것을
목표로 한다.

## 3. 사용자 정의

| 사용자 | 설명 |
|---|---|
| 개인 사용자 | 학습 목표, 기술 역량, 프로젝트 및 자격증 관리 |
| 시스템 관리자 | 시스템 설정, 데이터 및 서비스 운영 관리 |

초기 버전은 단일 사용자 환경을 기준으로 개발하며,
향후 다중 사용자 환경으로 확장할 수 있도록 설계한다.

## 4. 핵심 서비스 흐름

1. 목표 직무 및 필요 역량 정의
2. 현재 기술 역량 등록 및 평가
3. 실무 프로젝트 기반 기술 분석
4. 부족한 역량 및 학습 과제 도출
5. 기술 학습 및 독립 실습
6. 학습 결과 및 이해도 검증
7. 기술 블로그 및 포트폴리오 기록
8. 학습 계획 및 역량 수준 재조정

## 6. 기술 숙련도 평가 기준

| Level | 구분 | 평가 기준 |
|---|---|---|
| Level 0 | 미학습 | 해당 기술에 대한 학습 경험 없음 |
| Level 1 | 개념 이해 | 기본 개념과 사용 목적 설명 가능 |
| Level 2 | 기본 실습 | 예제 및 공식 문서를 기반으로 실습 가능 |
| Level 3 | 독립 구현 | 기본적인 기능을 독립적으로 구현 가능 |
| Level 4 | 문제 해결 | 오류 분석 및 시스템 개선 가능 |
| Level 5 | 심화 활용 | 성능 최적화 및 설계 의사결정 가능 |

숙련도 평가는 단순 학습 여부가 아닌
실습 결과 및 문제 해결 경험을 근거로 수행한다.

## 10. 초기 MVP 완료 기준

- 목표 직무 및 학습 목표 등록 가능
- 학습 과제 생성, 조회, 수정 및 삭제 가능
- 학습 과제 완료 처리 및 진행률 산출 가능
- 자격증 및 시험 일정 관리 가능
- 대시보드에서 주요 성장 현황 조회 가능
- 서비스 재시작 이후에도 데이터 유지
- 핵심 기능 테스트 완료
- 개발 환경 및 실행 방법 문서화

## 11. 개발 제약사항

- 초기 개발은 개인용 단일 사용자 환경을 기준으로 한다.
- 회사 소스코드 및 비공개 데이터는 사용하지 않는다.
- 외부 AI API에 회사 기밀 정보를 전송하지 않는다.
- API Key 및 인증정보는 GitHub에 등록하지 않는다.
- 초기 개발에서는 불필요한 클라우드 비용을 최소화한다.
- 고도화 기능은 초기 MVP 검증 이후 적용한다.
- 실제 구현 및 검증 결과를 기반으로 개발 이력을 기록한다.
