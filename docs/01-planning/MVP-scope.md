## 2. MVP 개발 목적

개인의 기술 성장 관리에 필요한 최소 기능을 구현하여
실제로 사용할 수 있는 초기 플랫폼을 구축한다.

초기 버전에서는 AI 기능보다 데이터 관리,
서비스 구조 설계 및 핵심 기능 구현에 집중한다.

## 4. 사용자 이용 흐름

1. 목표 직무 등록
2. 학습 목표 설정
3. 세부 학습 과제 등록
4. 학습 및 실습 수행
5. 학습 결과 기록
6. 과제 완료 처리
7. 대시보드에서 진행률 확인

## 5. 초기 개발 제외 범위

- AI 학습 튜터
- RAG 기반 기술 문서 검색
- 실무 프로젝트 기반 기술 분석
- 채용공고 자동 분석
- 기술면접 자동 생성
- 다중 사용자 관리
- AWS 클라우드 배포
- GPU 모델 서빙 및 추론 최적화

해당 기능은 후속 버전에서 단계적으로 개발한다.

## 6. MVP 완료 기준

- 목표 및 학습 과제 등록, 조회, 수정, 삭제 가능
- 학습 과제 완료 처리 가능
- 목표별 진행률 자동 계산
- 자격증 및 시험 일정 관리 가능
- 학습 노트 작성 및 조회 가능
- 서비스 재시작 후 데이터 유지
- 핵심 기능 테스트 통과
- 설치 및 실행 방법 문서화
